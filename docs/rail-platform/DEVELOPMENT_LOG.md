- 聊天窗口提供历史对话、新对话、项目上下文、建议问题、文本、图片/音视频/文档附件、图片预览、文件下载、清空与外部服务状态。

### 数据层与 API

- 新增迁移 `008_ai_assistant.sql`，建立 `ai_conversations`、`ai_messages`、`ai_attachments` 三张表及用户/会话时间索引。对话可选关联项目，消息保留 completed/failed 状态、稳定错误码和可选上游消息编号。
- 实现 `/api/v1/assistant/status`、`conversations/**`、`attachments/**` 接口，覆盖对话列表、创建、读取、发送、清空，以及附件申请上传、完成校验、删除、预览和下载。
- 附件沿用私有 MinIO/S3 桶与预签名直传，对象键使用 `assistant/<user>/<conversation>/...` 前缀。默认单附件 50 MiB，支持常见图片、音频、视频、文本、PDF、Office 和 ZIP，拒绝可执行文件与 SVG。
- 清空当前对话会在事务中删除消息与附件关系并重置标题，再逐个清理对象文件；对象删除失败会留下审计元数据。

### 外部 AI 适配器

- 通过 `AI_ASSISTANT_API_URL`、`AI_ASSISTANT_API_KEY`、`AI_ASSISTANT_MODEL`、`AI_ASSISTANT_TIMEOUT_MS` 和 `AI_ASSISTANT_MAX_ATTACHMENT_BYTES` 配置，浏览器不获得服务密钥。
- 平台后端只向完整 API 地址发送当前用户、可选项目、对话编号、系统提示、最近 50 条已完成消息和附件短时签名 URL。接受 `{ content, messageId? }` 或 `{ data: { content, messageId? } }` 响应。
- 外部服务未配置、超时、限流、返回非 2xx 或格式无效时，保存 failed 助手消息与错误码，不伪造成功回复，也不回滚已经保存的用户消息。
