- Playwright 覆盖登录/退出、注册开关、资料、项目、上传预览、日志和 AI 弹窗。
- 项目、资产、任务、对话等列表使用稳定分页并在目标规模测量性能。
- 核心 API 生成机器可读 OpenAPI，外部适配器有版本与契约测试。
- 结构化日志、请求耗时、错误率、连接池、对象存储和适配器指标可告警。
- 明确审计、通知、AI 对话、失败上传和孤立对象的保留/清理策略。
- 负载、24 小时稳定性、依赖漏洞和权限评审闭环；企业 SMTP 随邮箱找回密码移除而不再是部署门禁。
