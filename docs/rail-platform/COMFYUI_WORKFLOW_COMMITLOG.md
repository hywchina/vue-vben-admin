# ComfyUI 工作流集成变更记录

## 目标

完成工作流注册、管理员管理、能力映射、独立持久化 Worker 与文生图端到端链路。正式能力仅发布文生图，但代码和数据模型允许后续导入其他 ComfyUI API 工作流。

## 变更分组

### 1. 数据模型与首发工作流

- 新增顺序迁移 `010_comfyui_workflows.sql`。
- 新增工作流定义、不可变版本、能力、能力绑定、任务执行、输出回执和 Worker 心跳表。
- 为任务增加工作流版本外键和 `cancelling` 状态。
- 新增管理员工作流权限和文生图应用/能力。
- 将已验证的 Flux2 Klein 文生图 API JSON 纳入仓库并由种子脚本幂等登记。

### 2. ComfyUI 适配器与 Worker

- 实现 `/prompt`、`/history/{prompt_id}`、`/queue`、`/view`、`/interrupt` 协议。
- 实现超时、输出大小限制、可选服务端令牌和稳定错误处理。
- 实现数据库租约、心跳、重启恢复、轮询重试和取消。
- 实现输出 MIME/扩展名校验、私有对象存储、资产版本、标签、任务输出和审计。
- 使用输出回执避免重复登记；提交确认中断时禁止自动重投。

### 3. 平台 API

- 新增公开能力参数查询。
- 新增管理员工作流列表、注册、更新、版本发布和能力绑定接口。
- 任务创建固定工作流版本快照，防止管理员后续切换改变运行中任务。
- 任务列表返回外部编号、工作流版本和结构化错误。
- 取消任务转换为 Worker 可恢复的取消请求。

### 4. Web

- 新增管理员“工作流管理”页面。
- 文生图工作区改为由服务端参数定义驱动，支持基础/高级参数、提交、轮询、取消、失败反馈和结果预览。
- 任务状态增加“取消中”，活动任务判断包含该状态。

### 5. 部署与配置

- 新增全部 ComfyUI 服务端环境变量示例。
- 开发命令并行启动 API 与 Worker。
- 生产镜像增加 Worker 目标，生产 Compose 增加独立 `platform-worker` 服务。

### 6. 测试

- 参数映射、输出映射和非法节点校验测试。
- 配置和客户端协议测试。
- Worker 输出提取测试。
- 临时模拟 ComfyUI HTTP 服务测试完整提交、排队、完成、下载与取消协议。
- 模拟服务只存在于测试文件，运行时未增加任何模拟成功路径。

## 外部依赖与限制

- 本机没有可访问的真实 ComfyUI，真实 GPU 推理尚未在本机验证。
- 来源工作流已在其他电脑验证，但目标部署仍需安装对应模型与自定义节点。
- 本期只绑定并发布 `text-to-image`；其他工作流文件没有批量导入或对用户发布。
