## ComfyUI 工作流发布门禁（2026-08-08）

- 工作流 API JSON、参数节点、输入字段和输出节点必须在登记时完成结构校验。
- 18 份工作流的每个非连线输入必须由公开参数或媒体输入映射覆盖；更新 ComfyUI 节点后需基于真实 `/object_info` 重生成并运行完整性测试。
- 用户能力接口不得返回节点编号、原始工作流、外部地址或服务端令牌。
- 任务必须固定 `workflow_version_id`，切换绑定后历史和运行中任务不得漂移。
- 必须验证页面关闭后继续、Worker 重启租约恢复、幂等输出回执、取消、超时和连续轮询失败。
- 必须使用临时模拟 ComfyUI 验证 `/prompt`、`/history`、`/queue`、`/view` 和取消协议。
- 发布到真实环境前必须补做真实 ComfyUI、真实模型、MinIO 资产预览和 GPU 长任务验收；本机模拟测试不能替代该门禁。
- `ADAPTER_NOT_CONFIGURED`、外部执行失败或输出登记失败时不得产生成功任务或占位资产。
- 暂存输出不得自动进入资产中心；仅本人原设计会话的可用生成图片允许作为后续任务输入，须校验真实输出血缘、会话、用户、项目及可用当前版本。跨会话、训练/报告及旧调试流转仍要求已登记资产。
- 设计草稿必须按当前用户、项目、设计会话和应用隔离；恢复资产时重新校验会话归属、登记状态、项目范围、输入位和类型，不能信任浏览器缓存。
- 同一设计会话只允许一个 `queued`、`running` 或 `cancelling` 任务，不同会话可并行；必须由后端事务互斥保证，不能只依赖按钮禁用。
- 普通用户的跨应用复用只能发生在当前设计会话内，用户仍须明确确认暂存输出加入项目资产；管理员旧实例流转仅作为单功能调试兼容链路。
- 多轮工作区必须从任务台账恢复参数、有序输入和输出；带图片对比节点的能力只能从服务端工作流快照只读推断，不能修改原始 API JSON 或依赖浏览器静态名单。
- 分区任务必须保持 `job_inputs.asset_id` 为 Worker 消费的原图，并通过独立标记快照恢复用户输入；输出对比左图必须是标记前原图，不能使用标记图或其他轮次图片冒充。
