# 产品需求与验收基线

> 文档版本：1.0；基线日期：2026-08-04状态：平台框架基线；外部 AI/工作流执行服务不在本阶段实现范围内

## 1. 产品目标

本产品是轨道交通客室智能设计的统一工作平台，不是单页演示或多个外部 API 的简单拼接。平台负责长期稳定的用户、权限、项目、资产、任务、通知、审计和个人 AI 会话；ComfyUI、大模型、LoRA 训练、2D 生 3D、报告生成等计算能力通过有版本的适配器契约接入。

成功标准是：用户能在受控项目上下文中完成输入资产登记、应用调用、任务追踪和输出资产沉淀；数据在刷新、重启和跨用户场景下仍正确，权限由后端强制执行，关键行为可审计，部署和故障恢复可以复现。

## 2. 用户与职责

| 角色 | 主要职责 | 强制边界 |
| --- | --- | --- |
| `admin` | 用户与角色管理、全局项目可见、全局日志查看 | 不能在个人资料页修改角色；不能停用或降级最后一名启用管理员 |
| `user` | 在参与的项目中管理资产、任务、应用和个人日志/AI 对话 | 不能管理角色或读取其他用户的日志、项目和 AI 对话 |

平台角色只有 `admin` 和 `user`；项目内另有 `owner`、`editor`、`viewer`。两层授权解决的问题不同，不能相互替代。

## 3. 核心领域关系

1. **项目**是协作、授权和数据隔离上下文。
2. **资产**是可追溯、可复用、可版本化的多模态输入与输出。
3. **应用**是外部能力目录与契约，不直接拥有用户数据。
4. **任务**记录应用在项目中消费的资产、参数、状态和输出。
5. **设计会话**属于当前用户和项目，可按轮次组合多个应用；应用不直接拥有用户会话。
6. **AI 对话**属于个人数据，可关联项目和附件，但不会自动成为项目公共资产。
7. **审计事件**记录请求和关键业务动作，不记录密码、令牌、聊天正文或文件内容。

## 5. 非功能需求

下列数值是建议验收基线，需产品负责人和部署单位在试运行前确认；未确认前不能对外宣称达到相应 SLA。

| 编号 | 质量属性 | 建议验收标准 | 当前结论 |
| --- | --- | --- | --- |
| NFR-SEC-01 | 数据隔离 | 所有资源由后端校验身份、权限和项目范围；越权自动回归 | 已建立核心回归 |
| NFR-SEC-02 | 生产配置 | 不得使用开发 JWT、管理员密码、存储凭据或通配 CORS | 已实现启动校验 |
| NFR-DATA-01 | 数据完整性 | 关键关系有外键/唯一约束/事务；对象采用两阶段登记 | 已实现 |
| NFR-REL-01 | 就绪 | live 只反映进程；ready 同时检查 PostgreSQL 和对象存储 | 已实现 |
| NFR-REL-02 | 恢复 | 建议 RPO≤24 小时、RTO≤4 小时，每季度恢复演练 | 未验证，P0 |
| NFR-PERF-01 | 性能 | 建议非上传 API 基准负载 P95<800 ms、错误率<1% | 未建立基线，P1 |
| NFR-SCALE-01 | 列表 | 超过 200 条的集合必须稳定分页，不得无界返回 | 部分实现，P1 |
| NFR-OPS-01 | 可观测性 | Request ID、结构化日志、指标和告警可关联 | 部分实现，P1 |
| NFR-COMP-01 | 浏览器 | 支持单位统一 Chrome/Edge 最新两个大版本 | 待确认与自动化 |

## 6. 当前范围之外

- ComfyUI、大模型、LoRA、3D、报告服务的算法、GPU 调度和模型生命周期。
- 企业 SSO、组织架构同步和正式邮件/证书/域名/灾备资源。
- 算法效果、生成内容合规和模型许可证验收。

这些能力必须通过独立契约接入，不能直接耦合进用户、项目和资产核心模块。

## 7. 需求变更规则

新增需求必须具备需求编号、用户价值、权限与数据范围、异常路径、验收标准、迁移影响和测试层级。没有验收标准的功能不得直接进入开发。

## ComfyUI 工作流能力验收补充（2026-08-08）

- 管理员可以登记 ComfyUI API JSON、发布不可变版本、启停工作流，并把已发布版本绑定到平台能力。
- 普通用户只能看到能力参数，不得获取 ComfyUI 地址、令牌、节点编号或原始工作流 JSON。
- 18 项能力共用同一版本化执行链路；生成结果先写入私有对象存储并作为任务暂存结果，只有用户确认后才进入资产中心。
- 页面关闭、浏览器刷新和 Worker 重启不得丢失任务；恢复时不得因不确定的提交状态自动重复生成。
- 未配置服务、参数错误、外部执行失败、缺少输出和结果暂存失败必须返回稳定错误，不得使用占位图片伪造成功。
- 管理员切换能力绑定只影响新任务，历史任务必须保留实际执行的工作流版本血缘。
