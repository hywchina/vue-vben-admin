# AI 助手简化方案（待用户确认）

本轮只交付视觉方案，未修改运行时代码、数据库或现有会话。

## 需求与方案

- AI 助手作为个人全局会话，不绑定具体项目；切换项目不影响当前对话，历史按用户隔离。
- 顶部保留助手名称、历史、新建、关闭。历史中的重命名和删除进入次级操作；服务/模型详情与错误状态按需展示。
- 删除项目栏、常驻模型名称、顶部装饰线、条纹背景和英文空状态标语。
- 内容区使用白底留白，两条轻量快捷问题；底部保留输入、附件和发送。
- 新图标采用“对话气泡 + 灵感星芒”，标题用红色线稿，悬浮入口用红底白色图形。后续实现时制作统一矢量资产。

## 现有代码核实

- `apps/web-antd/src/components/assistant/ai-assistant.vue` 的 `contextProjectName` 会回退到当前项目；新建会话调用 `createAiConversationApi(platformStore.currentProjectId || undefined)`。
- `apps/web-antd/src/api/platform/assistant.ts` 的创建参数 `projectId` 为可选；正式开发时需停止主动传入当前项目，并检查后端上下文构造、历史会话兼容与隔离测试，不能仅隐藏界面文字。
- 会话、消息及附件仍应按当前用户隔离，不因去掉项目绑定而改变权限边界。
