# 资产中心布局对比：第二轮

状态：效果图，待用户确认。仅新增方案文件，不修改运行页面；所有缩略图、数量、任务编号均为示例。

## 本轮调整

减少首屏筛选控件：保留搜索、匹配方式、筛选入口、排序和视图切换。任务、文件类型、创建人、时间等筛选收进面板；排序下拉统一选择字段与正序/倒序。文件卡片只保留缩略图、名称和一行元数据，操作按悬浮或选中展示。

| 方案 | 分类与文件夹组织 | 适合场景 |
| --- | --- | --- |
| A 目录树 | 左侧生成分类及嵌套目录，右侧资源网格 | 多级目录较多，频繁跨目录整理 |
| B 顶部分类 | 顶部生成类别标签，文件夹卡片及面包屑逐级浏览 | 优先浏览大图，希望内容区更宽 |
| C 模块栏 | 左侧紧凑模块图标栏，右侧目录入口与图片网格 | 经常切换生成类别，接近用户提供的参考布局 |

方案仅确认资产工作区结构；生成图的全局图标和菜单细节不作为开发规格，开发时保留当前真实平台外壳。B 图重点呈现内部工作区，没有画出全局侧栏，不代表删除平台导航。当前项目范围与 AI 助手继续保留。生成类别不替代八类文件类型。精准搜索字段与筛选面板的具体交互在布局确认后细化。
