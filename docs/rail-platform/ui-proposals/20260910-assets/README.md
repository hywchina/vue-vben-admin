# 资产中心 UI 方案 V1

- 日期：2026-09-10
- 状态：效果图，待用户确认；未开发业务功能。
- 基础：当前工作区资产中心及白色平台外壳，保留已有未提交修改。
- 生成方式：内置 imagegen。

## 需求理解

保留全局平台导航，在资产中心内部增加 CMF、零部件、客室、报告四个生成分类，每个分类内展示多级文件夹。右侧采用资源网格，顶部集中提供项目、文件类型、来源任务、创建人、创建时间筛选，排序字段与正序/倒序切换，以及模糊/精准搜索。保留登记资产、新建文件夹、收藏、网格/列表和批量操作入口。

## 本版展示约定

效果图选择单个项目，展开 CMF → 材质方案 → 座椅面料；所有缩略图、数量、任务编号和日期均为示例。沿用品牌红与浅灰白色体系，用户附图用于参考左侧模块/右侧网格的结构。未分类用于承接上传素材或无法识别生成类别的历史资产。

拟定搜索规则：模糊模式按名称、业务编号、标签包含关键词查询；精准模式按所选搜索字段完整匹配。具体字段控件及交互在确认后细化。生成分类是业务维度，不替换既有八类文件类型。

全部项目聚合视图需保留权限范围；文件夹写入仍需明确项目。效果图不意味着已实现分类归属、任务筛选或精准搜索接口。
