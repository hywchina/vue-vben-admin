# 设计工作台：确认五类内容后的三版效果图

## 已确认的内容范围

本轮用户已确认以下五类内容，且同意把原“我的设计任务”改称“我的设计”。本轮三版都同时保留五个独立模块，不再把设计会话与单次执行合并为一个列表，也不把成果与已保存资产隐藏在同一个切换页签中。

1. **我的设计**：设计会话名称、所属项目、轮次、最近更新时间和最新一轮状态；入口为继续设计，可进入会话查看历史。
2. **我的项目资产**：可访问项目名称、资产数量、更新时间；进入资产、新建项目、管理项目。
3. **最近任务**：每一次具体执行，覆盖设计生成、模型训练、报告生成；显示名称、所属项目、类型、状态、时间；运行中展示进度与停止入口，完成后查看结果。
4. **最近设计成果**：最近生成的内容，可能尚未保存；展示缩略图、名称、项目、时间和保存状态，可预览、深化或保存至项目。
5. **最近保存资产**：已经保存/上传入库的资产，展示文件名（含类型扩展名）、项目、保存时间；可预览、下载和进入所在目录。

辅助入口为“新建设计”以及页尾“管理与记录”。用户权限和工作流管理仅管理员可见。没有添加大数字统计卡、成员管理表、完整日志或资产批量操作。

## 三版布局

- **01 均衡总览（推荐）**：上层我的设计 + 项目资产，中层全宽最近任务，下层最近成果 + 最近保存资产。按“继续工作 → 查看执行 → 找到产物”的顺序阅读，最接近用户原先认可的 A 版。
- **02 设计优先**：左侧大幅展示设计会话和成果；右侧纵向排列最近任务、项目资产、最近保存资产。更重视继续设计，但右侧信息较多，需要滚动。
- **03 成果优先**：首屏大幅成果图廊；下方三列为我的设计、最近任务、项目/已保存资产。适合先看成果、再决定下一步的工作方式；桌面宽屏更有优势。

五类模块保持语义一致，布局不同；演示中保存资产包含上传的参考图，体现其与生成成果不是同一个集合。我的设计展示最新一轮状态，而最近任务中的生成记录是该会话的一次具体执行，两处有关联但职责不同。
