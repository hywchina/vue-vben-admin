# 设计工作台 A 版细化提案

用户已倾向上一轮 A 版，本轮在“任务、项目资产、设计成果”的结构内制作三种细化方案。没有修改业务页面、路由、API 或数据库。图中名称、数量、时间、状态和图片都是布局示例，不表示当前运行数据。

## 三版对比

| 版本 | 布局 | 与上一版 A 的变化 | 适合场景 |
| --- | --- | --- | --- |
| A1 平衡精简 | 上方任务约 63%、项目约 37%；下方全宽成果图廊 | 精简状态与操作，普通行操作降低红色强调；项目管理进入二级视图，新建项目留在项目板块；保留成果/保存资产页签 | 最接近已认可的 A，改动少、容易理解 |
| A2 工作优先 | 左侧约 65% 为任务与最近成果，右侧约 35% 为项目和最近保存资产 | 任务区去掉外层卡片边框；成果与已保存资产同时可见，用图廊/文件列表区分，减少切换；右侧统一承载项目素材相关入口 | 日常继续设计、找素材与查进度，推荐进一步深化 |
| A3 成果优先 | 大幅成果图廊在上，任务和项目在下 | 减少成果区面板边框，放大图片；首屏视觉重心从状态列表转到方案成果，任务只显示最近两条 | 设计成果回顾、方案挑选、图像驱动的工作习惯 |

三版共同保持顶部品牌、平台标签栏、左侧导航、品牌红及浅色背景。不增加大数字统计卡；只保留一个“新建设计”主按钮，低频管理入口继续放在页尾。

A1/A3 使用“最近设计成果 / 最近保存资产”切换。A2 将未必入库的生成成果与已保存资产分开展示：左侧结果图廊展示最近生成内容，右侧用紧凑文件列表展示最近保存内容；已保存的生成结果可能在两个视图中出现，这是不同时间与用途维度，不应在实现时误认为数据重复并删除。

## 可检查内容

- `workbench-a-refinements.html`：三版可切换对比，支持最近/进行中筛选；A1/A3 可切换最近保存资产。设计调节项支持紧凑间距与管理员入口显隐。
- `workbench-a1.png`、`workbench-a2.png`、`workbench-a3.png`：桌面效果图。
- `preview.html`：浏览器验证包装页。
- `verify.mjs`：截图与验证脚本；使用 Playwright Chromium，可用 `RAIL_BROWSER_EXECUTABLE` 指定本机浏览器路径。

已逐版检查桌面渲染，验证任务筛选、保存视图、A2 保存列表，以及 1024/736/360px 无水平溢出；无浏览器脚本异常。业务按钮仅显示操作去向，不执行真实平台动作。

后续真实实现仍应沿用上一轮 README 的数据定义：我的任务按当前账号隔离，项目资产按可访问项目范围查询，最近保存时间必须来自真实保存事件；未保存成果不能当作已入库资产。确认布局之前不进行业务改造。
